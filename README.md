# 🎨 Background Color Changer

A simple and interactive **Background Color Changer** built using React.js. Change the background color with a click and explore different colors.

## 🚀 Live Demo

**[View Live Website](https://aayush-shrivastav.github.io/background-color-changer/)**

## ✨ Features

- 🎨 Change background colors interactively.
- ⚛️ Built with React.js.
- ⚡ Bundled using Parcel.
- 📱 Simple and user-friendly interface.
- 🔄 Instant color changes.

## 🛠️ Tech Stack

- React.js
- JavaScript
- HTML5
- CSS3
- Parcel

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/aayush-shrivastav/background-color-changer.git
```

### 2. Navigate to the project folder

```bash
cd background-color-changer
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm start
```

Open the local URL displayed in your terminal.

## 📦 Build for Production

```bash
npm run build
```

The production build is generated in the `dist` folder.
